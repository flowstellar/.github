### Stellar ecosystem project

</div>

An AI-powered payment assistant on the Stellar network that turns a sentence into a settled transaction.

### Inside the repo

- **Conversational interface** — "Send $50 USDT to wallet XYZ"
- **Real settlement** — transactions submitted to Stellar testnet/mainnet, not simulated
- **Instant confirmation** — the transaction hash comes back to the user in the same flow

### On-chain on Stellar

Built for the **Stellar** network with **Soroban** smart contracts — transactions are public and auditable.
